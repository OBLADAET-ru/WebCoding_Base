## 📖 О проекте

**WEBCODE x ART** — это открытый учебник и база знаний для веб-разработчиков, дизайнеров и всех, кто хочет создавать современные сайты и веб-приложения. Здесь собрана вся необходимая теория и практика: от того, как работает браузер и HTML, до настройки серверов, баз данных и деплоя проектов.

Проект не привязан к одному языку или фреймворку. В базе собраны лучшие практики Frontend и Backend разработки, современные подходы к дизайну (UI/UX) и работе с кодом. Это не просто статьи, а руководство к действию.

---

## ✨ Особенности

- 🎨 **Тёмная тема** с акцентным синим цветом (`#0033ff`)
- 🔍 **Мгновенный поиск** по всем разделам с выпадающими результатами
- 📱 **Адаптивный дизайн** — работает на телефонах, планшетах и ПК
- 🧭 **SPA-навигация** — переключение разделов без перезагрузки страницы
- 📝 **Подсветка синтаксиса** кода (CSS-классы `.kw`, `.str`, `.num`, `.cmt`, `.fn`)
- 🃏 **Интерактивные карточки** с hover-эффектами и свечением
- 📊 **Таблицы и callout-блоки** для важной информации

## 🚀 Быстрый старт

### Вариант 1: Просто открыть в браузере

```bash
# Клонируйте репозиторий
git clone https://github.com/OBLADAET-ru/webcode-art.git

# Перейдите в папку проекта
cd webcode-art

# Откройте index.html в браузере
# (или используйте Live Server в VS Code)
```

### Вариант 2: Локальный сервер (рекомендуется)

```bash
# Python 3
python -m http.server 8000

# Или Node.js (если установлен http-server)
npx http-server

# Откройте http://localhost:8000
```

## 🛠 Технологии

Проект намеренно написан на **чистом HTML, CSS и JavaScript** — без сборщиков, фреймворков и зависимостей. Это делает его:

- ⚡ **Быстрым** — загружается мгновенно
- 🪶 **Лёгким** — один файл, никаких `node_modules`
- 🎓 **Обучающим** — можно читать исходный код и учиться
- 🔧 **Простым в поддержке** — не нужно обновлять зависимости

| Технология | Назначение |
|-----------|-----------|
| HTML5 | Семантическая разметка |
| CSS3 | Стилизация, Grid, Flexbox, анимации |
| Vanilla JavaScript | Навигация, поиск, интерактивность |
| Google Fonts | Inter + Fira Code |

## 🔍 Как пользоваться поиском

Введите в строку поиска вверху любую тему:

- `Flexbox` → переключит на §2 (HTML & CSS)
- `React` → переключит на §4 (Фреймворки)
- `SQL` → переключит на §6 (Базы данных)
- `Figma` → переключит на §9 (Figma)
- `XSS` → переключит на §13 (Безопасность)

Поиск ищет по **заголовкам**, **описаниям** и **названиям разделов**.

## 🎨 Кастомизация

Все цвета и размеры вынесены в CSS-переменные в `:root`. Чтобы изменить тему, отредактируйте:

```css
:root {
    --bg: #000000;              /* Фон */
    --bg-surface: #0a0a0a;      /* Фон карточек */
    --bg-code: #111111;         /* Фон кода */
    --text-main: #ffffff;       /* Основной текст */
    --text-muted: #888888;      /* Второстепенный текст */
    --accent: #0033ff;          /* Акцентный цвет */
    --accent-glow: rgba(0, 51, 255, 0.4);  /* Свечение */
    --border: #1e1e1e;          /* Границы */
}
```

Например, чтобы сделать **зелёную тему**:

```css
--accent: #00ff88;
--accent-glow: rgba(0, 255, 136, 0.4);
```
